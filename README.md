# 牛马对账（NewMoreDataChecker）

用于核对上海速创与聚合力两套账单数据。当前主版本为无需数据库的纯浏览器 Web 应用，账单不会上传到服务器。

## 版本

- **v2.0.0 — 牛马对账 Web 版**：当前版本，代码位于 [`web`](web)。
- **v1.0.0 — Delphi 归档版**：原始桌面程序，通过 Git 标签 `v1.0.0` 保留，不再继续开发。

## Web 版主要能力

- 按“财务年月 + 业务年月 + 身份证号”汇总匹配。
- 精确到分核对社保、公积金、服务费和对账总金额四类差额。
- 浏览器内直接读取 `.xls` / `.xlsx`，不导入数据库。
- 支持大文件逐行读取与内存安全限制。
- 支持结果筛选和格式化 Excel 导出。
- 可选客户清单补充客户组及发包方名称。

## 本地运行

需要 Node.js 20 或更高版本。

```powershell
cd web
npm ci
npm run dev
```

验证与生产构建：

```powershell
npm test
npm run build
```

更完整的使用、字段规则、大文件限制和阿里云部署说明见 [`web/README.md`](web/README.md)。

## 数据安全

仓库不包含真实账单、核对导出文件或本地编译产物。Excel 文件仅由使用者在自己的浏览器中选择和处理。
