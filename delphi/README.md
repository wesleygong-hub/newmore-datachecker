# Delphi 1.0 归档

此目录保存“牛马对账”原始 Delphi 桌面版本，仅用于历史查阅和维护，不再作为当前主版本开发。

## 目录内容

- `NewMoreDataChecker.dpr` / `.dproj`：Delphi 工程入口与项目配置。
- `Unit1.pas` / `.dfm`：账单导入、SQL 核对、Excel 导出及牛马语录界面。
- `PUBLIC/`：原工程依赖的公共单元和窗体。
- `上海速创-聚合力对账.sql`：原数据库核对 SQL 参考。

该版本需要原有 Delphi、数据库连接及相关运行环境。无需数据库的当前 Web 版本直接位于[仓库根目录](../)。

正式历史快照请查看 Git 标签 [`v1.0.0`](https://github.com/wesleygong-hub/newmore-datachecker/tree/v1.0.0)。
