# v2.0.0 — 牛马对账 Web 版

NewMoreDataChecker 完成从 Delphi + 数据库桌面程序到纯浏览器 Web 应用的重构。

## 主要更新

- 无需数据库，Excel 文件只在当前浏览器中读取和核对。
- 按“财务年月 + 业务年月 + 身份证号”汇总匹配。
- 精确到分核对社保、公积金、服务费和对账总金额四类差额。
- 支持速创单文件、聚合力多文件及可选客户清单。
- 支持大体积 `.xlsx` 逐行解析和内存安全限制。
- 支持结果筛选、分页、错误明细及格式化 Excel 导出。
- 加入“牛马对账”品牌界面、等待语录轮播及结果自嘲文案。
- 提供阿里云轻量服务器 Nginx 静态部署示例。

## 验证

- 17 项自动化测试全部通过。
- TypeScript 检查及 Vite 生产构建通过。
- 已使用历史账单完成浏览器端回归验证。

详细使用说明见仓库根目录的 `README.md`。
